
# Lab 2 – Interactive Portfolio Enhancements

## Project details

GitHub Repository: https://github.com/samadhi084/LAB2-JAVASCRIPT

## Description

The purpose of this project is to improve my portfolio by adding a feedback form with input validation and interactive features. This feedback form works in both mobile and desktop browsers

## Features

- **Full Name Validation:** Checks that the name is entered and contains at least two characters. It allows letters, spaces, apostrophes, and hyphens.
- **Email Validation:** Checks that the email address has a valid format.
- **Topic Selection:** Requires the user to select a topic from the dropdown list.
- **Comments Validation:** Requires at least 15 characters in the comments field.
- **Live Character Counter:** Updates the character count while the user types.
- **Website Validation:** Allows the website field to be empty but checks the URL format if a value is entered.
- **Visual Validation Feedback:** Displays error messages and red borders for invalid fields and green borders for valid fields.
- **Success Message:** Displays a personalized message after successful form submission. The message disappears after four seconds.
- **Clear Button:** Resets all form fields, validation messages, and visual states.
- **Keyboard Focus Styles:** Makes the selected form element easier to identify when using a keyboard.

## Technologies

- HTML5 – to create the page structure and feedback form.
- CSS3 – to style the form and display different validation states.
- Vanilla JavaScript – to validate user input and handle form interactions.
- No external JavaScript libraries or frameworks are used.

## How to Run 

1. Download or clone the repository from GitHub.
2. Open the project folder on your computer.
3. Find the `index.html` file.
4. Double-click `index.html` to open it in a web browser.
5. Navigate to the Feedback page using the portfolio navigation menu.
6. Try entering information into the form and test the validation features.
